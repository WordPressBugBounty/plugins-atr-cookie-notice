באנר הסכמה לעוגיות המתאים לחוק הגנת הפרטיות בישראל (תיקון 13).

== Description ==

**ATR Cookie Notice** הוא תוסף ניהול הסכמה לעוגיות חזק וידידותי למשתמש המיועד לסייע לאתרי WordPress ליישר קו עם חוקי הגנת הפרטיות בישראל (כולל תיקון 13) ובמדינות נוספות, ועם פרקטיקות פרטיות מקובלות. לתוסף שני מצבים: מלא (חוסם, עם אפשרויות הסכמה מפורטות ובאנר מותאם אישית) ופשוט (ללא חסימה, מידע בלבד).

### תכונות עיקריות

* **מוכוון חוק ישראלי** - מיועד ליישור קו עם חוק הגנת הפרטיות (כולל תיקון 13)
* **בקרת עוגיות מפורטת** - אפשרויות הסכמה נפרדות לעוגיות חיוניות, אנליטיקה ושיווק
* **עיצוב מותאם אישית** - שליטה מלאה בצבעים, מיקום ועיצוב עם בוררי צבעים של WordPress
* **תוכן מותאם אישית** - שליטה מלאה בטקסט הבאנר, כפתורים ופוטר HTML עם תמיכה בטוקנים
* **מיקומי באנר מרובים** - אפשרויות מיקום בתחתית, למעלה או כשכבת-על במרכז
* **פונקציונליות הסתרה אוטומטית** - סגירה אוטומטית אופציונלית של הבאנר
* **תמיכה ב-RTL** - תמיכה נכונה בשפות מימין לשמאל
* **עיצוב רספונסיבי** - עובד בצורה מושלמת בכל המכשירים וגדלי המסך
* **תמיכה רב-לשונית** - תרגומים מובנים לעברית ואנגלית
* **ידידותי למפתחים** - הוקים ופילטרים נרחבים להתאמה אישית
* **אינטגרציה עם מדיניות פרטיות** - ניהול מובנה של מדיניות פרטיות
* **ניהול תפוגת עוגיות** - משך הסכמה ניתן להגדרה
* **מצב דיבוג** - כלי פיתוח לבדיקה ופתרון בעיות
* **מצבי הסכמה** - בחירה בין מלא (חוסם לא‑חיוניות עד להסכמה) לפשוט (מידע בלבד)
* **כלים** - כפתור "ניקוי מטמון ורענון משאבים" בלחיצה אחת עם cache busting, איפוס עיצוב לברירת מחדל

### קטגוריות עוגיות

התוסף מנהל שלוש קטגוריות עוגיות עיקריות:

1. **עוגיות חיוניות** - תמיד מופעלות, נדרשות לתפקוד בסיסי של האתר
2. **עוגיות אנליטיקה** - אופציונליות, לאנליטיקה של האתר וניטור ביצועים
3. **עוגיות שיווק** - אופציונליות, לפרסום ומטרות שיווק

### אפשרויות התאמה אישית

* **התאמה ויזואלית** - בוררי צבעים של WordPress לצבע ראשי, צבע טקסט, צבע רקע עם תצוגה מקדימה חיה
* **בקרת מיקום** - בחר ממיקום תחתית, למעלה או כשכבת-על במרכז
* **הגדרות התנהגות** - עיכוב הסתרה אוטומטית, משך תפוגת עוגיות
* **CSS מותאם אישית** - הוסיפו כללי עיצוב משלכם
* **מצבים ברירת מחדל** - הגדירו מצבי הסכמה ברירת מחדל לכל קטגוריית עוגיות
* **התאמת תוכן** - התאימו טקסט באנר, כפתורים ופוטר HTML עם תמיכה בטוקנים ({site_name}, {privacy_url}, {privacy_link})
* **פריסטים לעיצוב** - פריסטים של בהיר, כהה, מינימלי, ניגודיות גבוהה להגדרה מהירה

### פרטיות ותאימות

* **ניהול הסכמה** - מעקב ואחסון נכון של הסכמה
* **מדיניות פרטיות** - תבניות מדיניות פרטיות מובנות בעברית ואנגלית
* **הגנת נתונים** - טיפול מאובטח בנתוני הסכמת משתמשים
* **יישור קו רגולטורי** - מוכוון לחוק הגנת הפרטיות (PPL) בישראל, כולל תיקון 13 (אינו ייעוץ משפטי)

### תכונות למפתחים

* **תקני קידוד WordPress** - עוקב אחר WPCS ופרקטיקות מומלצות
* **הוקים נרחבים** - התאמה אישית של התנהגות עם פעולות ופילטרים של WordPress
* **מותאם לביצועים** - השפעה מינימלית על ביצועי האתר

מושלם עבור עסקים, סוכנויות ומפתחים הזקוקים לפתרון ניהול הסכמה לעוגיות אמין המיושר עם הדין הישראלי ושניתן להתאים בקלות לכל עיצוב אתר.

== התקנה ==

1. העלו את קבצי התוסף לתיקייה `/wp-content/plugins/atr-cookie-notice`, או התקינו את התוסף דרך מסך התוספים של WordPress ישירות.
2. הפעל את התוסף דרך מסך 'תוספים' ב-WordPress
3. עברו להגדרות → **ATR Cookie Notice** כדי להגדיר את התוסף
4. סמנו **הפעל באנר עוגיות** כדי להציג את הודעת העוגיות למבקרים
5. התאימו את מראה הבאנר, ההתנהגות וקטגוריות העוגיות לפי הצורך
6. השתמשו בתצוגה המקדימה החיה כדי לראות שינויים בזמן אמת
7. הקישו **שמור הגדרות** כדי להחיל את השינויים שלך
8. באנר העוגיות יופיע אוטומטית בחזית האתר שלך

== שאלות ותשובות ==

= האם צריך להגדיר משהו לאחר ההתקנה? =

התוסף עובד כברירת מחדל במצב מלא עם הגדרות בסיסיות. מומלץ להתאים את המראה, קטגוריות העוגיות, ואם צריך – לשנות את מצב ההסכמה ל"פשוט" (מידע בלבד). בדף הגדרות התוסף ניתן להגדיר צבעים, מיקום, קטגוריות ומצב ההסכמה.

= האם התוסף מסייע לעמידה בחוק הישראלי? =

ATR Cookie Notice מיועד לסייע ליישור קו עם חוק הגנת הפרטיות בישראל (כולל תיקון 13). במצב מלא (חוסם) ניתן להציג קטגוריות מפורטות, לתעד הסכמה ולחסום סקריפטים לא‑חיוניים עד לאישור. מצב פשוט הוא מידע בלבד ואינו חוסם עוגיות לא‑חיוניות. אינו מהווה ייעוץ משפטי – בדוק/י את דרישותיך מול גורם משפטי.

= האם ניתן להתאים את מראה באנר העוגיות? =

בהחלט! התוסף מציע אפשרויות התאמה אישית נרחבות כולל בוררי צבעים של WordPress עם תצוגה מקדימה חיה, מיקום, CSS מותאם אישית ופריסטים לעיצוב (בהיר, כהה, מינימלי, ניגודיות גבוהה). אתה יכול גם להתאים את טקסט הבאנר, הכפתורים ופוטר ה-HTML באמצעות טוקנים כמו {site_name}, {privacy_url} ו-{privacy_link}.

= מהם הטוקנים הזמינים לתוכן? =

אתה יכול להשתמש בטוקנים הבאים בטקסט באנר מותאם אישית ובפוטר HTML:
* {site_name} - שם האתר שלך
* {privacy_url} - כתובת URL של דף מדיניות הפרטיות
* {privacy_link} - תג anchor מלא עם קישור למדיניות הפרטיות
* [ok_button] - כפתור אישור (מצב פשוט)
* [accept_all_button] - כפתור קבל הכל (מצב מלא)
* [reject_button] - כפתור דחה (מצב מלא)
* [preferences_button] - כפתור העדפות (מצב מלא)
* [privacy_link] - קישור למדיניות פרטיות (מצב פשוט)


= האם התוסף תומך במספר שפות? =

כן, התוסף כולל תמיכה מובנית בעברית ואנגלית. תרגומים נוספים יכולים להיות מוספים דרך מערכת התרגום של WordPress.

= האם ניתן להגדיר מצבי ברירת מחדל שונים לקטגוריות עוגיות? =

כן, במצב מלא ניתן להגדיר אם עוגיות אנליטיקה ושיווק מופעלות או מושבתות כברירת מחדל. עוגיות חיוניות תמיד מופעלות מאחר שהן נדרשות לתפקוד בסיסי של האתר. במצב פשוט אין מתגי קטגוריות.

= כמה זמן התוסף זוכר את הסכמת המשתמש? =

כברירת מחדל, ההסכמה נזכרת למשך 365 ימים, אך ניתן להתאים זאת בהגדרות התוסף. משתמשים יכולים לשנות את ההעדפות שלהם בכל עת.

= האם יש דרך לבדוק את התוסף לפני הפרסום? =

כן, התוסף כולל מצב דיבוג המספק מידע מפורט בקונסולת הדפדפן, מה שמקל על בדיקה ופתרון בעיות במהלך הפיתוח.

= הבאנר או קבצים מעודכנים לא נטענים בחלק מהעמודים =

ראשית, נקו מטמון דפים ו‑CDN כרגיל (וגם מטמוני אופטימיזציה אם קיימים). אם הבעיה נמשכת, השתמשו ב"כלים" בדף הגדרות התוסף:

1. היכנסו להגדרות התוסף בלוח הבקרה
2. לחצו על "ניקוי מטמון ורענון משאבים" (מוסיף חותמת זמן ל‑CSS/JS ומנסה ניקוי מטמונים נפוצים)
3. רעננו עמוד פרונטאנד בחלון גלישה פרטית; כתובות המשאבים יכללו `?ver={גרסה}-{חותמת_זמן}`

אם משתמשים בתוספי מטמון, minification או אופטימיזציית JS, ייתכן שיהיה צורך להחריג את קבצי ה-JavaScript של התוסף מ:
* Minify/Combine
* Defer/Delay loading
* Async loading
* CDN delivery

נדרשת החרגת הקבצים הבאים:
* `/wp-content/plugins/atr-cookie-notice/public/js/atr-cookie-notice-public.js`
* `/wp-content/plugins/atr-cookie-notice/admin/js/atr-cookie-notice-admin.js`

לאחר ביצוע שינויים, השתמשו בכלי "ניקוי מטמון ורענון משאבים" ובדקו בחלון דפדפן פרטי.

= כיצד ניתן להתאים את תוכן הבאנר (טקסט וכפתורים)? =

בלשונית "תוכן" ניתן להחליף את ה‑HTML של טקסט הבאנר (`.scb-text`), אזור הפעולות (`.scb-actions`) בשני המצבים, ואת הפוטר (`.scb-footer`) במצב מלא. טוקנים זמינים:

- `{site_name}`, `{privacy_url}`, `{privacy_link}` (אלמנט קישור מלא עם כותרת עמוד מדיניות הפרטיות)
- במצב פשוט: `[ok_button]`, `[privacy_link]`
- במצב מלא: `[accept_all_button]`, `[reject_button]`, `[preferences_button]`

אבטחה: התוסף אוכף מזהי כפתורים נדרשים ומסנן את ה‑HTML.

= האם ניתן להתאים פריסט עיצוב? =

כן, אבל עליך לשמור את הפריסט תחילה לפני ביצוע שינויים מותאמים אישית. אם בוחרים פריסט עיצוב (בהיר, כהה, מינימלי או ניגודיות גבוהה) ורוצים להתאים אותו עוד יותר בלשונית עיצוב ומראה, בצעו את השלבים הבאים:

1. בחרו את הפריסט הרצוי מהתפריט הנפתח
2. הקישו **שמור הגדרות** כדי להחיל את הפריסט
3. בצעו את השינויים המותאמים אישית שלך בלשונית עיצוב ומראה
4. הקישו **שמור הגדרות** שוב כדי לשמור את ההתאמות שלך

אם תבצעו שינויים מבלי לשמור את הפריסט תחילה, תאבד את ערכי הפריסט.

= האם אני יכול לאפס הגדרות עיצוב לברירת מחדל? =

כן! בסעיף כלים של הגדרות התוסף, תמצאו כפתור "איפוס עיצוב לברירת מחדל" שמאפס רק את הגדרות העיצוב והמראה תוך שמירה על כל שאר ההגדרות ללא שינוי. הודעת אישור מונעת איפוסים בטעות.

= האם קיימת תצוגה מקדימה חיה? =

כן. בדף ההגדרות יש תצוגה מקדימה חיה צפה שמתעדכנת מיידית בעת שינוי השדות (כולל בוררי הצבעים והפריסטים). השינויים אינם משפיעים על האתר עד לשמירה.

== הצהרת אחריות ==

התוסף מסופק "כפי שהוא" ללא אחריות מכל סוג, מפורשת או משתמעת. מטרתו לסייע לבעלי אתרים ליישר קו בממשק וחוויית הסכמה לעוגיות עם חוק הגנת הפרטיות בישראל (כולל תיקון 13). התוסף אינו מהווה ייעוץ משפטי ואינו מבטיח עמידה בדרישות החוק. האחריות לבדיקת החובות המשפטיות ולתצורה נכונה של התוסף לצרכים הייחודיים שלך מוטלת עליך בלבד. המחבר והתורמים אינם אחראים לכל נזק, הפסד או אי-עמידה שינבעו מהשימוש בתוסף זה.
